# Sheet-to-Art — Brand Identity & Logo Concepts

This directory contains the preserved visual identity research and candidate logo concepts developed for **Sheet-to-Art**.

## Preserved Concepts

1. **Concept 1: The Metamorphic Grid (Prism Cell)**
   - *Theme*: Order $\to$ Elevation. A 2×2 tabular cell matrix where the top-right cell transcends into an isometric art prism facet.
   - *Assets*: `concept1_metamorphic_grid.svg`, `concept1_icon.svg`
   - *Colors*: Electric Cobalt (`#2563EB`), Radiant Coral (`#EA580C`), Sky Cyan (`#0284C7`)
   - *Typography*: Neo-Grotesque (`Geist` / `Inter`)

2. **Concept 2: The Dynamic S-A Monogram (Kinetic Flow)**
   - *Theme*: Stream $\to$ Apex. A continuous unbroken geometric ribbon connecting the fluid data stream ('S') to the structural architectural apex ('A').
   - *Assets*: `concept2_sa_monogram.svg`, `concept2_icon.svg`
   - *Colors*: Royal Indigo (`#4F46E5`), Golden Amber (`#D97706`), Iris (`#818CF8`)
   - *Typography*: Humanist Geometric Sans (`Plus Jakarta Sans`)

3. **Concept 3: The Golden Folio (Swiss Edition)**
   - *Theme*: Editorial Canon $\to$ Print Heritage. Rooted in Jan Tschichold's golden canon of page construction, modular grid guides, and golden focal quadrant.
   - *Assets*: `concept3_golden_folio.svg`, `concept3_icon.svg`
   - *Colors*: Obsidian Black (`#18181B`), Swiss Vermillion (`#DC2626`), Tactile Vellum (`#FDFBF7`)
   - *Typography*: High-contrast editorial serif (`Instrument Serif` / `Georgia`) + Swiss monospace

## How to View the Interactive Presentation

An interactive presentation containing light/dark modes, responsive mobile layouts, 60px/32px/16px favicon simulators, and monochrome comparisons is available at:

- File: `brand_identity_presentation.html` (and `/root/brand_identity_presentation.html`)

To serve locally on port 5174:
```bash
python3 /root/scripts/serve_brand_presentation.py
```
Then visit:
- `http://localhost:5174/`
- `http://127.0.0.1:5174/`
- Or from a local network device: `http://<YOUR_IP>:5174/`
